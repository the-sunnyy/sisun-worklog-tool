주말은 빼고 평일만, 오늘 날짜까지만 불러옵니다. 공휴일·휴가 날은 건너뜁니다. 업무일지를 새로 반영하려면 Claude에게 "업무일지 업데이트해줘"라고 말해주세요.
고급 · Apps Script 직접 연결 (안 써도 됨)
평소에는 비워두세요. Claude가 업무일지를 읽어 이 폴더의 worklog-data.js에 넣어두면 그걸로 불러옵니다. 칸을 채우면 Apps Script(apps-script 폴더)로 직접 읽어옵니다.

업무 로그 불러온 내용이 여기 채워져요 · 직접 붙여넣기도 가능

날짜 줄(예: 9/8, 9/8(월), 2026-09-08)을 적고 그 아래에 그날 항목을 줄줄이 붙여넣으면, 날짜별로 자동으로 나눠서 처리합니다. 한 주치를 한 번에 붙여넣어도 됩니다.
중복 확인 · 트래킹 시트 기록과 대조 대조할 기록 없음
Claude가 읽어둔 트래킹 시트(디자인2팀의 사본)의 진선 기록과 이름이 겹치는 행에 중복 의심을 붙입니다. 트래킹 시트는 회사 계정 전용이라 API 키로는 읽을 수 없어요(403 오류).

제외 · 판정 기준 보기
  • 빼는 줄 회의·미팅·스터디·교육·확인·인수인계 같은 내부 업무, 시선 템플릿 제작, "수정"만 한 줄
  • 날짜 요청일 = 처음 나온 날 · 완료일 = "전달"이 처음 나온 날 (같은 기획전은 한 줄로)
  • 레벨 A 신규제작 · B 템플릿 활용 · C 광고주 PSD · D 비즈보드·썸네일·언어 베리 · E 사이즈 베리
  • 비즈보드 세트 기준 (set 2종 → 썸네일 1 / 베리 1)
  • 확인 필요 표시된 행은 표에서 직접 고쳐서 복사
